# schoolista

This workspace is a Next.js app.

## Pulled LMS Source

The `schoolista_lms` remote points to https://github.com/riyjein/schoolista_LMS.git. Its Vite/React LMS source has been pulled into `src/`, including `src/app/routes.tsx`.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
